# 🚀 Password Strength Checker

> A lightweight CLI utility to evaluate password strength using rule-based validation and pattern analysis.

---

## 📌 Overview

**Password Strength Checker** is a simple command-line tool that analyzes user passwords and classifies them as **Weak, Medium, Strong, or Very Strong**.

It applies practical security rules such as password length, character diversity, and common pattern detection to provide clear feedback and actionable improvement suggestions.

This project is part of my ongoing effort to build **clean, maintainable, and production-oriented code** while strengthening core programming fundamentals.

---

## 🎯 Objectives

- Solve a real-world security problem  
- Apply string processing and regular expressions effectively  
- Follow clean coding and modular design principles  
- Build a reusable and extensible validation utility  

---

## ⚙️ Features

- Password strength classification (Weak → Very Strong)
- Rule-based validation (length, uppercase, lowercase, digits, symbols)
- Common password blacklist detection
- Weak pattern identification (sequences, repetition)
- Security scoring system (0–100)
- Actionable suggestions to improve password strength
